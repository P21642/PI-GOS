# Legado - versão console (GOS_Console)

Primeira versão do sistema, em console, que já conversa com o MySQL.
Fica aqui **apenas como referência** para a integração (`Database.cs` e
`Repositories.cs`). A aplicação final é a versão desktop em `src/GOS_Visual`.

`database_antigo.sql` é o esquema que esta versão usava (4 tabelas, sem
`cancelado` e sem auditoria). O esquema atual do projeto está em
`database/database.sql`.
